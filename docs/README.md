## 默认决策（评审时可改）

1. **一期只做上门服务**，不做到店预约。到店预约作为小程序类目审核不通过时的备选方案。
2. **一期不做优惠券。** 二期集团券用微信支付"预充值代金券"，门店券用"免充值代金券"。
3. **退款不等分账回退。** 先从门店子商户余额退给用户，集团那份异步回退给门店，回退失败的记入追偿台账。
4. **一键求助由门店店长和集团客服按值班表处理**，超时没人确认就升级到集团安全负责人。
5. **售后由门店先处理**；门店 24 小时没处理，或用户不接受门店的结果，由集团客服裁决，门店必须执行。
6. **技师中止服务**核实为用户原因的，不退款，技师照拿提成，用户拉黑。
7. **不为未满 18 周岁的人提供服务**，下单前要做健康告知和年龄确认。
8. **用户发票由服务门店开具。**

### v0.3 原型评审回写（2026-10-01）

- 门店派单成功直接进入已接单；首次派单期限固定；确认改约或已接订单被迫重派时开启新轮，每轮期限不因切换候选或重试延长（02、13）。
- 请假只自动改派受影响技师的已接单、未出发订单，已开始履约与已完成订单保持原状态（02、12）。
- 正常完成须服务满预约及已支付加钟时长；用户要求提前结束单独选择，不自动退款（02）。
- 求助结案区分未解争议与服务是否已完成，保留完成事实和最新终态，分账阻断全部解除后才恢复结算（05、13）。
- 协商退款按各笔申请额比例拆分到分，采用最大余数补齐；确认后固定明细，退款重试不重分配（03、11）。
- 沿用原型的一期可配置默认值：肩颈45分钟日间198元、21:00起夜间228元；提现申请成功创建计入每日3次，失败和撤销仍计，前置失败与幂等重复不计，按Asia/Shanghai自然日统计（02、04）。
- 09 补充相关验收场景。这些是交付要求，尚须在真实后台、微信支付及小程序目标环境完成验收。
