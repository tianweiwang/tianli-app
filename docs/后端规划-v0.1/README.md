## 本次范围

按“网页管理后台 + 服务端”一起规划。门店、集团使用一套后台工程，按账号权限显示菜单和数据；用户、技师、店长小程序使用同一套业务服务。开发顺序以最新预约版 V4 主链路为建议起点，V3 的完整履约能力保留在需求映射中；正式首发客户端范围仍待确认。

## 建议方案

1. 后台前端采用 Vue 3 + TypeScript + Element Plus。门店、集团共用组件和详情结构。
2. 服务端采用 Java + Spring Boot 的模块化单体；业务按模块划分，订单和资金共享数据库事务。
3. MySQL 保存业务事实、资源占用和资金流水；Redis 用于展示缓存和限流。
4. 后台列表负责找问题，详情负责做决定。交易、履约、售后、安全、结算分别记录状态，在详情中组合展示。
5. 先完成基础权限、门店技师、排班与项目，再完成预约支付、变更和退款，随后补齐分账、佣金、售后、安全与生命周期。所有一期模块完成后才进入正式上线验收。
