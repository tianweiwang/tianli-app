# 07 页面清单

下面是一期各端的全部页面，和 [01 第 5 节](01-产品概述与一期范围.md) 的交付清单一一对应。每个页面要出哪些状态图，见 [13-状态与操作矩阵](13-状态与操作矩阵.md)；"弹层"指在当前页弹出，不单独成页。

## 用户端

| 页面 | 说明 |
| --- | --- |
| 首页 | 服务项目、当前地址是否在服务范围内、附近可约技师（距离、评分、最近可约时间） |
| 项目详情 | 一口价（注明"已含上门交通费，无其他附加费用"）、时长、服务流程、加钟价、禁忌人群说明 |
| 选技师 / 技师详情 | 按距离和评分排序；详情显示培训批次、证书编号、擅长项目、评分（不足 5 条显示"新技师"）、评价；也可以选"就近安排" |
| 选时段和地址 | 只显示可约时段，时段价直接显示总价 |
| 实名核验 | 第一次下单前，姓名 + 身份证号，含单独同意弹窗 |
| 健康告知（弹层） | 第一次下单弹出完整告知；之后在确认页勾选 |
| 确认订单与支付 | 技师（就近安排时显示系统选定的技师）、时段、地址、服务对象、总价、取消规则摘要（出发前免费、出发后扣 20%）、健康告知勾选、时段保留倒计时、微信支付 |
| 支付结果 | 支付成功，引导订阅消息；拒绝订阅时提示改用短信通知 |
| 订单列表 | 按状态筛选：进行中 / 待评价 / 售后 / 全部 |
| 订单详情 | 按订单状态显示不同的内容和操作（见 13 第 1 节） |
| 取消确认（弹层） | 显示能不能免费取消、要扣多少钱、能退多少钱 |
| 改约 | 重新选时段（只能选同价时段）或改地址（只能在原门店范围内）；显示剩余改约次数 |
| 改派 / 门店改约确认 | 显示原技师和新技师（或原时间和新时间），同意或拒绝，显示剩余确认时间 |
| 加钟（弹层） | 选加钟单位，显示价格和支付倒计时 |
| 申请售后 / 售后进度 | 填写类型、诉求、描述、图片；进度显示门店处理结果、接受或申请集团介入 |
| 评价 | 星级、标签、文字 |
| 发票 | 申请开票（抬头、税号、邮箱）、查看下载、状态 |
| 推广中心 | 分销码和海报、推广协议、绑定客户数、佣金明细（按状态）、提现、免确认收款授权 |
| 安全中心 | 紧急联系人、一键求助、直接拨打 110 |
| 我的 | 地址管理、联系客服、隐私设置（查看和撤回同意）、注销账号 |
| 限制下单提示 | 原因类别、到期日、联系客服申诉 |

## 技师端

| 页面 | 说明 |
| --- | --- |
| 入驻 | 绑定账号、实名和人脸核身、上传证书和保单及工装照片、审核状态和驳回原因 |
| 工作台 | 今日订单、待确认订单（接单 / 拒单，显示剩余确认时间） |
| 订单详情 | 导航、出发/到达/开始/结束打卡（出发前要求授权位置；结束时可以选"用户要求提前结束"）、发起加钟、标记用户爽约、中止服务、一键求助；求助入口绑定当前订单 |
| 中止服务（弹层） | 选原因、补充说明，提示有危险先求助 |
| 排班 | 设置可接单时段、请假申请和审批状态 |
| 收入 | 提成明细（含取消补偿、中止服务、调整记录）、分销佣金、提现 |
| 我的档案 | 证书、保单及到期提醒、评分和评价、差评申诉、处罚记录和申诉、分销码 |

## 门店后台（网页）

| 页面 | 说明 |
| --- | --- |
| 订单看板 | 待派单池（显示派单剩余时间）、手动派单、店内改派、发起改约、确认用户爽约、异常订单（定位失败、未按时出发、超时未结束、退款待垫付） |
| 售后处理 | 待处理列表（显示剩余时间）、同意退款（全额或部分）、驳回（必须写理由）、协商 |
| 技师与排班 | 技师列表、排班日历、保单状态、请假审批（显示受影响的订单） |
| 投诉与评价 | 投诉处理和处罚、差评申诉初审、提出用户黑名单 |
| 规则设置 | 技师提成（有版本）、交通补贴、取消补偿比例、服务半径、营业时间、路程缓冲 |
| 门店设置 | 营业状态、设置暂停营业时段（显示受影响的订单） |
| 对账 | 每笔订单的分成明细、每日对账单、分账回退记录、技师提成台账（标记已发）、退款待垫付 |
| 发票 | 开票申请列表、上传发票、驳回、红冲 |
| 推广 | 门店二维码、店员和门店推广员管理 |
| 求助值班 | 接收告警、确认、填写处理结果 |

## 门店小程序简版

| 页面 | 说明 |
| --- | --- |
| 待派单 | 待派单提醒、手动派单、店内改派 |

## 集团后台（网页）

| 页面 | 说明 |
| --- | --- |

| 技师档案 | 导入结业名单、入驻审核、证书、培训批次、保单、调店、离职、照片审核 |

| 售后与客服 | 售后裁决、客服特批退款、中止服务核实 |
| 投诉与评价 | 投诉处理和处罚确认、处罚申诉复核、差评申诉终审 |
| 用户管理 | 黑名单审核、限制下单、用户申诉 |
| 安全中心 | 安全事件及处理记录、值班表 |
| 分销管理 | 集团推广员邀请、推广协议版本 |
| 数据看板 | 订单量、GMV、门店和技师排行、复购率 |
| 账号与权限 | 集团和门店账号、角色、操作日志 |
