# 01 产品概述与一期范围

一期在 1 个城市、3~5 家门店（建议）跑通"用户下单 → 就近门店派技师上门 → 自动分账"的闭环，只做上门服务，然后再推广到更多城市。

## 1. 背景

- 集团有直营和加盟门店，同时做按摩培训；学员结业拿证后派驻到各门店。
- 小程序让用户预约技师上门服务。订单收入在集团和门店之间自动分账，支持一级分销。

## 2. 产品定位

**持证技师 + 线下门店兜底。** 每位技师的培训和证书记录可以查，每个订单都有就近的门店负责。这是解决行业信任问题的卖点，也是通过微信审核的关键。

## 3. 角色与端

用户和技师共用一个小程序，按身份切换；门店和集团用网页后台，门店另有一个小程序简版。

| 端 | 使用者 | 形态 | 核心职责 |
| --- | --- | --- | --- |
| 用户端 | 顾客 | 微信小程序 | 选项目、选技师和时段、实名、健康告知、下单支付、看服务进度、取消、改约、加钟、售后、评价、开票、分销推广、一键求助 |
| 技师端 | 技师 | 同一小程序，切换身份 | 入驻、确认接单、排班请假、导航、出发/到达/开始/结束打卡、中止服务、一键求助、收入和提成明细、评价申诉、分销与提现 |
| 门店后台 | 店长、门店财务 | 网页 | 订单和派单、售后处理、技师和排班、投诉处理、提成规则、对账、开票、门店推广员、求助值班 |
| 门店小程序简版 | 店长 | 小程序 | 见本文第 5.4 节 |
| 集团后台 | 集团运营、财务、客服、安全负责人 | 网页 | 项目和定价、门店和技师的生命周期、规则和全局参数、分账监控、追偿台账、售后裁决、投诉处罚、黑名单、安全事件、数据看板 |

门店账号只能访问本店数据，接口和导出功能都一样。

## 4. 已确认的业务决策

| 事项 | 决定 |
| --- | --- |
| 资金流向 | 用户支付进服务门店的微信子商户；分账只分集团、门店两方 |
| 技师提成 | 系统计算，门店发放 |
| 加盟费、管理费 | 不在小程序里管理 |
| 集团抽成 | 按客户归属分两档（集团客户 / 门店客户），比例后台可配，可以按门店、项目单独设 |
| 直营店 | 和加盟店同一套逻辑；各自有独立营业执照和子商户，门店类型只用于报表 |
| 上门交通费 | 不单独显示，含在一口价里；靠服务半径和就近派单控制成本 |
| 分销 | 只做一级；分销员属于集团或门店，决定客户归属 |
| 跨店订单 | 用户下单时选了非归属门店服务：按服务门店的"集团客户"档抽成；原门店不分钱；分销佣金照发，改由集团出；客户归属不变 |
| 付款后改派门店 | 不允许，因为钱已经进了原门店的子商户；要换门店只能全额退款后重新下单 |
| 服务类型（默认） | 一期只做上门；到店预约作为类目审核不通过时的备选方案 |
| 优惠券（默认） | 一期不做；二期集团券用预充值代金券，门店券用免充值代金券 |
| 退款（默认） | 先从门店余额退给用户，不等分账回退；回退失败的记入追偿台账 |
| 求助值班（默认） | 门店店长 + 集团客服按值班表处理，超时升级到集团安全负责人 |
| 售后裁决（默认） | 门店先处理；门店 24 小时没处理，或用户不接受门店的结果，由集团客服裁决，门店必须执行 |
| 技师中止服务（默认） | 核实为用户原因的，不退款，技师照拿提成，用户拉黑 |
| 未成年人（默认） | 不为未满 18 周岁的人提供服务 |
| 用户发票（默认） | 由服务门店开具 |

## 5. 一期范围

这一节是报价和验收的依据，其他文档和这里冲突的，以这里为准。

### 5.1 一期完整交付

**用户端**
- 服务项目浏览，按地址匹配服务范围内的门店和技师
- 指定技师 / 就近安排、选时段、填写服务对象、健康告知、下单、微信支付、引导订阅消息
- 实名核验（第一次下单前）
- 订单进度、虚拟号码联系技师、取消、改约、加钟、确认或拒绝改派和门店改约
- 售后申请和进度、评价、发票申请
- 地址管理、紧急联系人、一键求助、联系客服、隐私设置、注销账号、限制下单提示
- 推广中心：分销码和海报、推广协议、绑定客户数、佣金明细、提现（含免确认收款授权）

**技师端**
- 入驻：绑定账号、实名和人脸核身、上传证书和保单及照片、查看审核状态
- 工作台：今日订单、待确认订单（接单 / 拒单）
- 订单详情：导航、出发/到达/开始/结束打卡（含提前结束）、发起加钟、标记用户爽约、中止服务、一键求助
- 排班和请假
- 收入：提成明细、分销佣金、提现
- 我的档案：证书、保单、评价和差评申诉、处罚记录和申诉、分销码

**门店后台（网页）**
- 订单看板：待派单池、手动派单、店内改派、发起改约、确认用户爽约、异常订单
- 售后处理：同意退款、驳回、协商
- 技师和排班、请假审批
- 投诉与处罚、差评申诉初审、提出用户黑名单
- 规则设置：技师提成、交通补贴、取消补偿比例、服务半径、营业时间、暂停营业
- 对账：每笔订单的分成明细、每日对账单、技师提成台账（标记已发）、退款待垫付
- 发票：处理用户开票申请、上传发票、红冲
- 门店二维码、店员和门店推广员管理
- 求助值班：接收告警、确认、记录处理结果

**集团后台（网页）**
- 服务项目、一口价、时段价、加钟单位和价格、健康告知和禁忌说明、文案审核
- 门店管理：门店生命周期（建档、进件、分账授权、上线审核、暂停、关停）
- 技师档案：导入结业名单、入驻审核、证书、培训批次、保单、调店、离职、照片审核
- 规则：集团抽成、分销佣金、全局参数（见 02 第 10 节）
- 资金：分账监控和人工处理、分账回退、追偿台账、佣金和提现管理、服务费对账单
- 售后裁决和客服特批、中止服务核实、投诉与处罚、差评申诉终审、黑名单审核
- 安全事件、值班表
- 分销员邀请、推广协议版本
- 账号和权限、基础数据看板（订单量、GMV、门店和技师排行、复购率）

**资金能力**
- 服务商模式下单、分账、完结分账、分账回退
- 全额退款、部分退款
- 商家转账（免确认授权模式，用户确认收款模式兜底）
- 每日对账

### 5.2 只预留数据结构（一期不做页面和流程）

- 优惠券：`coupon_template`、`user_coupon` 两张表，以及订单里的优惠字段
- 门店自定义价格：`store_service.price_override`
- 技师星级系数：`tech_commission_rule.star_coefficients`
- 合作机构类型的分销员（对公结算）

### 5.3 一期不做

- 到店预约
- 优惠券、营销活动、老带新返券
- 会员储值、套餐卡
- 合作机构推广
- 跨门店调度技师（技师临时去其他门店接单）
- 按路程估算的智能派单
- 企业团单
- 技师端 App（后台持续定位）
- 培训系统对接（一期手工导入结业名单）
- 加盟费、管理费管理

### 5.4 门店小程序简版

只包含店长在外面也要随时处理的操作：

1. 待派单提醒，手动派单和店内改派
2. 今日订单列表和状态
3. 接收求助告警，点"已确认"，填写处理结果
4. 查看技师今日排班
5. 售后待处理提醒，可以直接同意退款或驳回（24 小时时限内，在外面也能处理）
6. 紧急请假审批

其他操作都在门店网页后台完成。
