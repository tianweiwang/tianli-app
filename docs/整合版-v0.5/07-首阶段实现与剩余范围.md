## 1. 第一阶段实际交付

- 一个本地入口、五个角色视图，读取同一份订单和业务时钟；用户、门店、技师使用统一 ID。商品与预约分别保存多笔订单、整数分金额及操作记录。
- 商品：本人购物车/地址 → 提交占库存 → 模拟支付 → 集团整单发货 → 本人收货 → 等待期 → 集团出账 → 门店核对 → 付款及结果查询。
- 商品逆向：未发货整单取消、按商品部分退货/仅退款、仓储验收、退款失败/未知查询；验收分歧可申诉、复核、返还原货并确认收回；已付商品佣金冲减后生成追回记录，可登记分次回款。
- 预约：用户创建付款 → 技师确认或门店直接派单 → 开始与完成；保留固定派单期限、确认变更新开一轮、请假筛选、加时、求助及主单/加时分笔退款。

**业务数据仅在同一浏览器的本地存储中共享。** 角色切换是演示身份；真实登录授权、数据库并发、支付退款渠道、物流回调和跨设备同步尚未接入。
