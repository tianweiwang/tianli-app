## 2. 建议的演示参数

| 参数 | 本稿演示建议 | 约束 |
| --- | --- | --- |
| 商品待支付 | 15 分钟 | 必须核实支付关闭结果后再释放资源 |

| 商品佣金示例 | A 商品 10%，B 商品 20% | 仅用于 310 元订单、退 100 元后佣金由 40 变 30 的验算 |

| 佣金售后等待期 | 演示可配置 7 天 | 仅结算等待的演示参数，不能替代不同商品的实际售后权利与政策 |

## 3. 核心整合验收（A01～A40）

所有场景从同一业务数据出发，在用户、门店、集团之间验证关联结果；适用时包含刷新、重复点击、失败重试。

| 编号 | 前提与动作 | 必须得到的结果 |
| --- | --- | --- |
| A01 | 同一用户通过 A 店买商品，并向 B 店预约 | 商品集团收款/A 店佣金；服务 B 店收款；订单、售后、发票各自关联 |
| A02 | 拒绝定位后浏览商城、手选区域预约 | 两条流程均有继续入口，购物不强索定位 |
| A03 | 用户甲创建订单，切换用户乙看列表及进入详情链接 | 列表/详情/取消/退款均隔离；甲的资源和资金不变 |
| A04 | 一个账号切消费者、技师、店长；店长进入他店订单 | 不扩大身份权限；他店数据/导出拒绝，商品推广订单不暴露完整收件信息 |
| A05 | 服务安全限制生效，同时存在商品待收货单 | 不能新建被限制的服务；已有商品查看、物流和售后继续可用 |
| A06 | 已有预约 A 店客户归属，经 B 店商品分享下单 | 商品来源锁 B；预约归属 A 保持，商品不占预约首单 |
| A07 | 同用户先进入 A 商品入口再进入 B，带已有购物车结账 | 按 D02 定稿口径展示最终来源与变更提示，提交后固定 |
| A08 | 商品单提交后再扫另一门店码，然后支付原单 | 原单推广门店、比例、销售主体与价格不变 |
| A09 | 自然进入、推广记录到期、无效码、推广资格撤销分别下单 | 无有效来源时无门店佣金并记无需结算；不自动用预约归属兜底，错误码有说明 |
| A10 | 两位用户先后接受不同商品推广入口 | 登录身份不改变，购物车/会员/推广上下文互不串号 |
| A11 | 商品有不同 SKU，数量零/负数/超过库存，或已下架 | 不能提交无效订单；错误指出可更正项，不产生扣款 |
| A12 | 两个用户提交最后一件商品，先提交的一单超时 | 有效占用最多 1 件；确认未付款后只释放一次，第二用户可重新购买 |
| A13 | 待支付期间商品改价；支付后商品改名或下架 | 待支付和已付订单按已定快照规则处理，历史明细不被商品当前值覆盖 |
| A14 | 新增/修改地址簿、不可配送地址、提交后修改地址 | 可选地址并校验配送；修改地址簿不改订单快照；订单改址走确认流程 |
| A15 | 重复提交、双击支付、支付结果未知、重复成功通知 | 同一请求一笔订单/支付；未知先查，不重复扣库存或生成佣金 |
| A16 | 支付超时后回调成功，但库存已分配给他人 | 不超卖、不静默丢款；核查原单并退款，失败有集团财务待办 |
| A17 | 商品成功支付后，集团登记真实模拟出库事件和运单 | 用户待发货→待收货；数量、地址、商品及运单一致，历史状态有时间线 |
| A18 | 用户申请未发货取消，仓库同时尝试发货 | 只一条流程获准；失败方看到最新状态，不能一边退款一边发货 |
| A19 | 多商品订单取消其中一行，剩余行继续发货 | 退款金额/运费方案明确，剩余数量履约，佣金按明细调整 |
| A20 | 物流停滞、丢件、错发、签收争议 | 集团工单有处理人和下一步；未解决不自动收货/结佣 |
| A21 | 用户确认收货，再重复确认或推进自动收货时间 | 收货仅生效一次，不重复奖励或结佣；争议分支禁止自动释放 |
| A22 | 退一件商品，寄回并经集团验收可售/不可售 | 退款和库存分别处理，可售才增加可售库存，不可售记报损或待处理 |
| A23 | 退货验收不符、用户未寄回、用户申诉；部分接受或驳回后返还货物 | 每个分支有超时/复核/关闭出口；寄回运费、运单及无人领取待办明确，不凭驳回清除未解决争议 |
| A24 | 两个售后案件争抢同一支付剩余额度，且有退款处理中；最终全退 | 成功退款+占额不超过实付；同一数量不重复退；全退未付佣金作废，已付转追回，不永久等收货 |
| A25 | 退款受理成功但实际失败/未知，再查询和重试 | 用户看到处理中或待处理；原退款号复用，成功金额只增加一次 |
| A26 | 310 元样例，商品 A 退 100 元，再退运费 10 元；再验多次小额退款 | 商品佣金 40→30→30；净实付 310→210→200；小额退款按累计净额重算，差额不因逐笔取整丢失 |
| A27 | 商品未发货或存在售后时手动完成结算 | 拒绝；仅状态按钮不能越过收货和售后条件 |
| A28 | 可结佣金入账单后发生退款，尚未付款 | 受影响明细冻结并调整，不继续按旧金额付；其他无争议明细可处理 |
| A29 | 门店佣金付款中时发生退款，支付结果未知 | 先核查付款；成功记追回、失败调账，不能同时恢复余额并重付 |
| A30 | 40 元佣金已付后产生 10 元冲减，后续佣金或人工回款偿还 | 债务为 10 元，可分次抵扣/回收至 0；无重复冲销，不强扣预约资金 |
| A31 | 出账、门店提差异、财务复核、付款失败再重试 | 账单明细、版本、凭证完整；审批与到账分离，付款幂等 |
| A32 | 门店暂停预约、撤销推广、最终关闭 | 三种动作有不同影响；旧商品由集团继续履约，历史应付应收不清零 |
| A33 | 商品与预约分别申请发票，之后部分退款 | 集团/服务门店分别开票，净额/红冲有对应记录；不跨主体合票 |
| A34 | 微信会员折扣支付商品，查看各端订单/消费/商品报表 | 原价、优惠、实付、成功退款、净额和佣金口径一致 |
| A35 | 新预约支付，技师拒绝，门店连续换候选，直到超时 | 初始截止不变；门店派单直接确认；到期未派出自动退款 |
| A36 | 用户确认改约/指定改派；门店建议被拒或过期 | 正确开启新轮或保留原约/退款；未确认不提前改变事实 |
| A37 | 批准紧急请假及重复审批，包含进行中和已完成预约 | 只符合条件的本人未开始订单入池；轮次不重复开启，进行中不回退 |
| A38 | 地点不覆盖、已付款申请改地点；取消时实际履约事实有争议 | 按 D05 定稿规则处理；覆盖、费用、理由、授权和争议出口齐全 |
| A39 | 未满时长正常完成、提前结束、求助后完成/退款再结案 | 正常完成受限；其他事实独立保留，结案不恢复已取消或已退款终态 |
| A40 | 主单和加时协商退款；两笔预约倒序完成、首单全退 | 分笔金额与占额正确；首单按 D06 定稿规则调整，商品订单不干扰 |

| E12 | 直播预告/直播中/结束，点击商品/预约，商品途中下架 | 跳到同一购买/预约校验链，保留有效推广来源；停播不影响已付订单 |
