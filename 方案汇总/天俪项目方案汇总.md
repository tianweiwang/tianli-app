## 一、项目定位与核心判断

**背景**
- 天俪是保健类集团，有直营和加盟门店，同时经营按摩培训；学员结业后派驻到各门店。
- 小程序提供上门服务预约：用户选门店、项目、技师、时段，钱付给服务门店，集团按规则分账。整合版演示里还加了集团自营商城。

**三个核心判断**
1. **小程序是加盟体系的"操作系统"，不是独立盈利的抽佣平台。** 集团抽成只有 5–15%，试点规模下平台本身一定亏损。它的价值在于带动招生、加盟、门店收入，以及集团对整个体系的掌控。
2. **天俪有三样别人学不来的资源**：自家培训学校（技师的供给和质量可控）、城市里的门店（服务兜底、空闲产能）、"正规、持证"的定位（对抗行业的信任问题）。所有设计都应该围绕放大这三样。
3. **试点的目的是验证，不是赚钱**：验证老客愿不愿意迁到线上、门店低谷时段有没有上门需求、复购和服务质量能不能稳住。

**飞轮**

```
培训学员 ──结业──▶ 持证技师 ──派驻──▶ 加盟门店
   ▲                                   │
   │                         小程序带来上门订单
   │                                   ▼
"毕业有单可接、真实收入可查" ◀── 技师收入↑、门店收入↑
   │                                   │
 招生更好招                   "加盟带订单" → 加盟更好卖、门店更少关店
```

## 二、商业模式

### 1. 为什么不能只靠平台抽成

- 298 元一单，集团抽 14.9 元（门店客户，5%）到 44.7 元（集团客户，15%）。
- **保本测算（假设）**：年平台成本按 300 万元，每单集团平均净得约 24 元，每年要约 12.5 万单，即每天约 350 单，大约要 35 家店同时运营。
- 试点 3–5 家店时平台必然亏损，应作为对加盟体系的投入来核算。

### 2. 集团的收入来源

| 收入来源 | 谁付钱 | 阶段 | 说明 |
| --- | --- | --- | --- |
| 培训学费 | 学员 | 已有 | 平台上的真实就业和接单数据，可以提高招生转化 |
| 进阶培训 | 技师 | 二期 | 和技师星级、分级定价挂钩：进阶 → 升星 → 单价更高 → 技师愿意为进阶付费 |
| 加盟费、管理费 | 门店 | 已有 | "带订单的加盟"能支撑更高的加盟价，或者改成"低加盟费 + 高抽成" |
| 平台抽成 | 门店（分账） | 一期 | 前期不是利润来源，是体系费用 |
| 上门标准包、耗材集采 | 门店 | 按需 | 精油、一次性床单、工装、上门包；统一品牌形象，也赚供应链差价 |
| 企业客户 | 企业 | 二期以后 | 员工福利、工间放松；跨门店签约，天然属于集团客户，还能填工作日白天的空闲 |
| 付费会员 | 用户 | 二期 | 收年费，权益是优先预约、会员价等；钱直接进集团，又不属于储值 |
| 储值、次卡 | 用户 | 二期以后 | 现金流好，但要先解决预付卡合规和跨主体清算 |
| 商城 | 用户 | 待定（F01） | 集团统一销售发货，门店按推广来源拿佣金 |

### 3. 单位经济

**上门要按技师占用时长定价。** 一单 60 分钟的服务，加上往返路程，技师实际被占用约 2 小时；到店只占约 70 分钟。所以上门价要明显高于到店价（约 1.5 倍），而且最好用来填门店的空闲时段：门店技师高峰做到店，低谷做上门，这部分几乎是纯增量收入。

一单 298 元的分配（门店客户、无分销，示意）：

| 去向 | 金额（元） |
| --- | --- |
| 集团抽成 5% | 14.90 |
| 支付手续费约 0.6%（由谁承担待定） | 约 1.79 |
| 技师提成 40% + 交通补贴 | 129.20 |
| 门店毛利（未扣耗材和管理成本） | 约 152 |

技师端测算（示意）：每天 4 个上门单，每单约 129 元，月入约 1.2 万元。宣传时只能用真实数据，不能承诺收入。

### 4. 获客路径（按成本从低到高）

1. **门店老客迁移到线上**：门店码绑定，集团按低档抽成。
2. **技师推荐**：分销码，既带来新客，也减少技师私下接单。
3. **企业客户**：一个合同带来一批稳定订单。
4. **私域运营**：企业微信、社群、复购提醒。
5. **公域内容**：视频号、小红书，内容尺度要严格把关。
6. **美团、大众点评**：量大但要付佣金，客户也不归你，适合引流后转到小程序复购。

**最核心的指标是复购率。** 保健按摩是高频消费，客户的长期价值远比单次抽成重要。

### 5. 商业模式上的红线

1. 不做"培训贷"，不承诺包就业、承诺收入；只展示真实的就业和接单数据。
2. 一期不做酒店上门，避免擦边印象。
3. 技师是雇员还是合作关系，决定社保、个税和用工风险。
4. 加盟宣传不能夸大"带订单"。
5. 做储值之前先解决预付卡合规。

## 三、引流钩子：体态评估

**状态**：整合版需求 02 第 11 节已把"检测、报告、复评"列为候选范围；采用人工问卷、人工评估还是设备影像还没定，不默认进入一期。

### 1. 先改名

保健门店不能做诊断。"脊椎检查""矫正""调理颈椎病"同时踩了广告法和医疗执业两条线；"免费体检 + 推销"也是监管重点打击的养生营销套路。

| 不要用 | 改用 |
| --- | --- |
| 脊椎检查、脊柱侧弯筛查 | 体态评估、姿态观察 |
| 诊断、矫正、治疗、调理、根治 | 观察、记录、放松建议 |
| "你的脊椎有问题" | "观察到右肩略高，建议关注" |
| 健康评测报告 | 体态观察记录 |

评估中发现持续疼痛、麻木等明显异常，要明确建议就医，不能接着推服务。

### 2. 好钩子的四个条件

| 条件 | 普通做法 | 好钩子的做法 |
| --- | --- | --- |
| 本身有价值 | 测完就推销 | 用户拿到看得懂、带走就能用的结果：标注过的体态照片 + 3 个居家拉伸动作 |
| 门槛低但不免费 | 免费 | 19.9 元，可全额抵扣首单；能挡掉薅羊毛的人，也摆脱"免费体检推销"的印象 |
| 能复测 | 一次性 | 4 周后免费复测，前后对比；对比只写"体态变化记录"，不写疗效 |
| 自然接上主营 | 当场办卡 | 结果页推荐服务方案、用户自己选；评估当天不推储值卡，写成门店规矩 |

### 3. 三层钩子

```
① 线上自测（小程序，0 元）
   拍正面、侧面照片 + 回答 5 道题 → 简版体态观察
                │
                ▼
② 门店体态评估（19.9 元，抵首单）  或  上门首单附送简版评估
   技师按标准流程拍照标注、测活动度 → 完整记录 + 推荐方案（可选）
                │
                ▼
③ 4 周后免费复测（提醒） → 前后对比 → 复购、套餐（二期）
```

### 4. 用户拿到的"体态观察记录"

1. 正面、侧面照片，标注头前伸、高低肩等能直接看出来的指标
2. 3 条大白话观察结论
3. 3 个居家拉伸动作，配短视频
4. 推荐服务方案，明确写"可选"
5. 复测日期和提醒
6. 免责说明：用于日常保健参考，不是医学诊断，持续疼痛请就医

照片要单独征得同意，只有用户本人和服务门店能看，规定保留期限，分享时只分享不带照片的版本。

### 5. 不同人群怎么用

| 人群 | 怎么用 | 说明 |
| --- | --- | --- |
| 白领 | 线上自测 + 晚间上门 | 主力人群，转化路径最短 |
| 企业 | 办公室集体体态筛查活动 | 企业客户的敲门砖 |
| 社区、物业 | 公益讲座 + 现场评估 | 门店周边获客 |
| 中老年 | 慎用 | 最容易被当成"免费体检推销"；要做就只评估、不推卡，最好有家属在场 |

### 6. 和系统、培训结合

- 评估时扫门店码绑定，客户归属门店，现有规则直接适用。
- "体态评估标准流程"做成技师进阶课程，考核通过才能做评估，也是集团的一门培训产品。
- 系统要加：评估服务类型、评估记录和对比页、复测提醒、照片单独同意。

### 7. 指标

| 指标 | 看什么 |
| --- | --- |
| 自测完成率 → 预约评估率 | 线上钩子有没有吸引力 |
| 评估后 7 天首单转化率 | 能不能接上主营 |
| 4 周复测率 | 循环有没有转起来 |
| 90 天复购率 | 最终价值 |
| 评估相关投诉率 | **红线**：升高说明门店在借评估强推 |

## 五、经营闭环功能

以《经营闭环补充》为准。P0 的标准是"试点中有人负责、能处理到底"，允许先由人工执行。

### 1. 最小 P0（9 项）

| 编号 | 工作项 | 一期做到什么程度 |
| --- | --- | --- |
| P0-01 | 店内忙碌统一占用 | 技师登记、店长代登记；开始、预计结束、延长、提前结束；和预约共用可用时段判断；不能覆盖已付款预约 |
| P0-02 | 实际履约事实 | 明确真实地点和覆盖范围，出发、到达由谁在哪里采集；异常核实和更正留痕 |
| P0-03 | 安全离开 | 和服务完成分开记录；超时进入值班核实和升级，不自动认定安全 |
| P0-04 | 服务资金链 | 分账、门店所得、技师提成、取消补偿、退款调整、回退追偿、发放和对账（原一期范围补齐） |
| P0-05 | 最小服务交接记录 | 按服务对象和订单记录注意事项、偏好、客观备注，下次重新确认；补"再次预约"入口 |
| P0-06 | 轻量回访 | 回访待办、负责人、期限、联系结果；发现问题转投诉、安全或退款案件 |
| P0-07 | 统一事项工作台 | 汇总派单、协助、售后、安全事项；认领、分派、超时接管、有结论才关闭 |
| P0-08 | 独立服务准入 | 审核名单、授权依据、审核人、适用项目、暂停记录；试点只用成熟技师时可先用名单管理 |
| P0-09 | 门店基础看板 | 今日和明日预约、空闲与占用、待办、实收实退、提成和来源明细 |

### 2. 其余项目

| 项目 | 优先级 | 说明 |
| --- | --- | --- |
| 复购提醒 | P1 | 先做"再次预约"；自动提醒要先定接收意愿、频率、去重 |
| 渠道来源统计 | P1 | 新客优惠按原二期；活动归因和佣金归属分开 |
| 体态评估 | 待定 | 先定评估形式、收费、报告责任，再排期 |
| 星级、进阶培训、激励 | P1 分步 | 先有评价、投诉、考核和复训记录，再做星级和激励 |
| 高级经营分析 | P1 | 先统一工作时长、店内占用、请假和缓冲的口径 |
| 多人预约、组合项目 | P2 | 试点期先分别预约、人工协调 |
| 门店物料领用 | 按需 / P2 | 先定内部领用、免费配发还是集团销售 |
| 门店考核评级 | 人工 P1 | 自动影响派单和曝光后置 |
| 培训数据回流 | 人工 P1 | 系统对接按原三期 |
| 企业客户 | P2 / 原三期 | 签约、额度、月结、开票单独设计 |
| 周期预约 | P2 | 先用"再次预约"预填 |
| 会员、次卡、储值 | 原二期 | 规则先行 |
| 加盟线索管理 | P2 | 试点期用表格管理 |
| 往来净额结算 | 分开推进 | 跨业务抵扣属于新增政策，后置 |

### 3. 三条原则

1. **新增功能不挤掉原有欠项**：发票、投诉评价、权限、隐私注销、门店和技师生命周期、商品退货和物流等继续保留。
2. **培训闭环先跑通**：考核授权 → 实际服务 → 评价与回访 → 问题反馈 → 复训 → 重新授权。这比先做星级页面更能验证培训有没有效果。
3. **先冻结一期范围，再排期报价**（F06）。

## 六、运营方案（运营经理视角）

### 1. 这个项目的运营特点

| 项目特点 | 对运营意味着什么 |
| --- | --- |
| 客户主要来自门店老客 | 重心是"老客迁移 + 复购"，不是砸钱投放；最重要的数据是每家店的老客绑定进度 |
| 门店是加盟商，运营指挥不动 | 抓手只有数据对比、激励政策、集团活动 |
| 技师来自自家培训学校，新手多 | 回访、复训比拉新更要紧 |
| 上门 + 安全和合规敏感 | 不能靠颜值营销，增长靠私域、口碑、企业客户 |
| 集团抽成薄 | 运营团队成本靠平台收入覆盖不了 |
| 一期没有优惠券、没有会员 | 几乎没有促销手段 |
| 上门占技师约 2 小时，晚高峰和到店撞车 | 真正要卖的是门店空闲时段，要按时段看供需 |

### 2. 五个运营问题和对策

1. **门店迁移老客反而要多交钱**：老客在店里付款不抽成，迁到线上要交 5% 和手续费，门店最理性的做法是不推。
   - **对策**：试点期门店客户抽成减免，比如前 3 个月 0%。
2. **晚高峰的上门单可能派不出去**：派单失败会自动退款，第一单体验就很差。
   - **对策**：试点期只开放门店低谷时段的上门，主动引导工作日白天的需求。
3. **一期几乎没有运营工具**。
   - **对策**：补 6 项最小工具，见下表。
4. **两套推广规则讲不清**：预约的客户绑定 365 天，商品的推广来源只算 24 小时。
   - **对策**：出一页纸的"推广收益说明"，规则能简化的尽量简化。
5. **试点规模下运营团队养不起**：日均约 50 单时，集团平台月净收入约 3.6 万元，远低于完整运营团队的成本。
   - **对策**：试点团队精简，运营费用按集团试点投入核算。

一期最小运营工具：

| 工具 | 解决什么 |
| --- | --- |
| 渠道码和关键埋点 | 知道哪个渠道有效、用户在哪一步流失 |
| 用户列表和筛选 | 按最近服务时间、次数、归属门店生成待联系名单 |
| 首页和公告配置 | 改文案、调项目顺序不用找开发 |
| 指标口径表 | 新客、复购、30 天复购率、实收、取消率、派单成功率、准时率的统一定义 |
| 门店推广执行数据 | 每家店新绑定客户数、店员和技师推广排行 |
| 迁移激励手段 | 最小版"门店首单立减"（门店出资的免充值券），或者线下礼品 |

### 7. 试点前要摸清的基线

1. **每家试点门店**：老客数量、能联系上多少（能不能加企业微信）、每月到店单量、技师人数、各时段空闲率、现有客单价、店长意愿、愿意开放上门的时段。
2. **技师**：谁能独立上门（成熟、自愿）、交通方式、有没有便携按摩床。
3. **周边**：服务半径内小区和写字楼的密度、可合作的物业和企业。
4. **本地竞品价格**：验证 298 元的定价站不站得住。

### 8. 试点 KPI

| KPI | 怎么算 | 验证什么 |
| --- | --- | --- |
| 门店老客绑定率 | 绑定的老客 ÷ 门店可联系的老客 | 迁移是否可行 |
| 绑定后首单转化率 | 绑定后 30 天内下首单的比例 | 线上预约有没有吸引力 |
| 低谷时段上门占比 | 上门单中工作日白天的比例 | "填空闲"假设是否成立 |
| 30 天复购率 | 首单后 30 天内再下单的客户比例 | 需求是否持续 |
| 派单成功率、准时率 | 按口径表统计 | 履约能力 |
| 投诉率、求助次数 | 每百单的投诉和求助数 | 服务质量和安全 |
| 技师人均每周上门单数 | 上门单数 ÷ 参与技师数 | 技师收入有没有吸引力 |

## 七、数据与分析

**结论**：交易和资金数据沉淀得很扎实，财务对账类分析够用；履约过程类分析基本够用，但取决于出发、到达能不能采集到；获客、渠道、漏斗、时段供需、运营动作效果，基本没有数据。架构上只有一个业务库，没有分析层和指标口径。

### 1. 已经做得好的

- **快照**：订单保存下单时的价格、分成规则、客户归属，可以准确对比政策调整前后的效果。
- **事件记录**：状态变化、派单轮次、改约改派、售后方案版本都有时间记录，接单时长、派单失败率等可以直接算。
- **状态分开存**：服务进度、退款、结算各自独立，统计不会互相覆盖。
- **资金到分**：支付、分账、退款、佣金、提成都有流水。
- **组织历史**：技师调店、门店生命周期有记录，历史订单归属准确。
- **培训批次**：技师表有培训批次字段，可以按批次看技师表现。

### 2. 运营问题对照

| 运营要回答的问题 | 现状 |
| --- | --- |
| 每家店老客迁移了多少 | 有绑定记录；缺门店线下老客基数，也分不清扫码的是老客还是新客 |
| 哪个渠道有效、获客成本多少 | 没有渠道来源记录，也没有投放成本数据 |
| 用户在哪一步流失 | 没有埋点 |
| 复购率、留存 | 能算，但口径没定义 |
| 回访、提醒有没有效果 | 只记"发了没有"，不记"点了没有、带来哪一单" |
| 哪些时段缺技师、哪些时段空着 | 只知道上门单，不知道到店占用和没约上的需求 |
| 准时率、迟到 | 取决于出发、到达的采集方式 |
| 取消、投诉都是什么原因 | 部分有分类，用户取消、派单失败、改派原因还是自由文本 |
| 培训有没有改善质量 | 评分、投诉、批次有；授权和复训记录没有 |

### 3. 架构上的四个问题

1. **报表直接查业务库**，会和下单、占用时段抢资源；至少要加一个只读副本。
2. **没有汇总层**，数据量一大看板就慢；需要每天定时计算的汇总表。
3. **业务事件记录可能被清理**：为可靠投递设计的事件处理完通常会删，分析用的事件日志要单独长期保存。
4. **隐私删除会抹掉分析数据**：用户注销后订单事实保留，身份换成无法还原的匿名编号。

### 4. 建议补的 10 项

| 补什么 | 具体内容 | 何时定 |
| --- | --- | --- |
| 1. 用户来源记录 | 首次进入的渠道、微信场景值、活动、门店、分销员、时间；订单也记下单来源；渠道和活动字典，投放成本可手工录入 | **建表前** |
| 2. 埋点规范 | 约 15 个关键事件（进首页、看项目、看技师、选时段、约满、提交、支付成功、点击提醒等），统一字段 | **建表前** |
| 3. 占用类型扩展 | 增加到店服务、休息、培训等类型，记录实际起止时间，和 P0-01 一起设计 | 随 P0 |
| 4. 约满记录 | 用户查不到可约时段时记一条，衡量没满足的需求 | 随 P0 |
| 5. 原因分类字典 | 取消、派单失败、改派、退款、投诉统一用分类码，加可选文字说明 | **建表前** |
| 6. 运营动作记录 | 回访任务和结果；触达记录（渠道、模板、活动、发送、点击、带来的订单） | 随 P0 |
| 7. 技师授权和复训记录 | 授权项目、资格、授权人、依据、有效期；复训原因、关联案件、结果 | 随 P0 |
| 8. 门店存量客户标识 | 导入会员名单按手机号匹配，或店员确认；每月录入门店线下基线数据 | 随 P0 |
| 9. 出发、到达的采集 | 和 P0-02 一起定 | **建表前** |
| 10. 匿名化规则 | 注销后保留订单事实、身份换成匿名编号；位置只保留到区县 | **建表前** |

**架构最小配置（试点期）**：只读副本 + 每天定时汇总 + 报表工具（开源的 Metabase、Superset，或帆软等国产工具）+ 一份指标口径表。多城市扩张后，再考虑专门的分析数据库和用户标签系统。

## 八、创新点

### 1. 用好"培训学校"

**① 技师成长档案：比证书更可信的服务履历**
- **是什么**：每位技师有真实可查的履历，比如"服务 326 次、复购率 48%、准时率 98%、零投诉"，以及培训和复训记录。
- **为什么只有天俪能做**：从培训到服务全程在自己手里。对用户是信任，对招生是证据，对技师是成长路径。
- **基础**：P0-06 回访、P0-08 准入，加上评价和投诉数据。

**② 学员实习体验**
- **是什么**：督导陪同下，学员以较低价格提供到店服务，按摩学校常见的"学生诊所"模式。
- **为什么有效**：价格敏感客户有了选择，学员得到实战，数据反馈给培训。
- **前提**：只在门店做、不上门，要等到店预约上线。

### 2. 用好"门店 + 上门"的组合

**③ 闲时上门价**
- **是什么**：工作日白天等门店低谷时段，上门价打折；以后在首页提示"今天下午附近有 3 位技师空闲"。
- **为什么有效**：直接验证"上门填空闲"这个核心假设。
- **基础**：需求里已有"时段价"功能，配置成白天降价几乎不用开发。

**④ 家庭保健师**
- **是什么**：用户选定专属技师，按月订阅，固定周期上门。
- **为什么有效**：收入可预测；客户关系留在平台里，从根本上减少私下接单；定位和普通上门平台拉开差距。
- **基础**：周期预约和订阅收费属于二期；试点期可先人工排期验证。

**⑤ 社区保健站和同小区连单**
- **社区保健站**：和物业合作，每周固定半天在小区驻点；公共空间更安全，体验后转成上门客户。
- **同小区连单**：邻居约连续时段，技师少跑路，可以给价格优惠。

### 3. 把"正规、安全"做成看得见的体验

**⑥ 服务小结**
- **是什么**：每次服务后，用户收到一份小结：重点放松部位、观察到的情况、居家建议、下次建议时间。
- **为什么有效**：成本低、专业感强，和擦边印象完全区分开；"下次建议时间"自然带出复购。
- **基础**：建立在 P0-05 服务交接记录上；只写保健建议，不写医疗判断。

**⑦ 安心上门：子女为父母预约**
- **是什么**：外地子女给父母下单，父母只接电话确认；子女收到服务进度和安全离开通知，能查看技师档案。
- **为什么有效**：中老年保健市场大，掏钱的往往是子女；女性用户和技师家人也看重安全。
- **基础**：已支持"服务对象可以不是下单人"；依赖 P0-02、P0-03 的履约事实。面向中老年绝不推销商品。

**⑧ 首单不满意全额退款**
- **是什么**：首单不满意，申请即退。
- **为什么适合现在**：一期没有优惠券，满意保障只用到已有的售后流程，比打折更显底气。
- **防滥用**：仅限首单、选择原因、滥用者进黑名单。

### 4. 用 AI 降低运营成本

**⑨ 店长、客服、技师的 AI 助手**
- **店长助手**：每日简报、异常提醒，起草差评回复和回访话术。
- **客服首答**：常见问题和订单查询先由 AI 回答；**安全、投诉、退款一律转人工。**
- **技师记录助手**：服务后语音口述，自动整理成服务记录和服务小结。
- **为什么重要**：让小团队覆盖更多门店，是运营成本和收入匹配的关键。

**⑩ 手机拍照体态评估和变化趋势**
- **是什么**：拍两张照片自动标出姿态指标，复测形成变化曲线。
- **底线**：只呈现观察和变化，不做诊断，不承诺效果。

### 5. 新渠道

**⑪ 权益采购**
- **是什么**：保险公司、银行、企业批量采购服务次数，作为保单权益、信用卡权益或员工福利。
- **为什么有效**：一次合作带来一批稳定订单，多在工作日白天，正好填空闲。
- **基础**：需要兑换码和核销，二期以后。

### 最推荐先试的三个

| 优先 | 创新点 | 理由 | 试点期怎么低成本验证 |
| --- | --- | --- | --- |
| 1 | 闲时上门价 | 几乎不用开发，直接验证核心假设 | 2 家店工作日 10–16 点降价 20%，跑 4 周，对比空闲填充率和技师收入 |
| 2 | 服务小结 + 技师成长档案 | 低成本建立信任，把培训闭环做实 | 试点技师手工填写小结，看收到小结的客户复购率是否更高 |
| 3 | 家庭保健师 / 为父母预约 | 定位升级、收入可预测、减少私下接单 | 找 10–20 位老客人工签月度专属技师，看订阅意愿和续订率 |

AI 助手建议从一开始纳入设计。一期不必再撑大，只需做三件事：把闲时价配置出来；让服务小结能手工填写；保证出发、到达、安全离开能采集到。

## 九、落地前要先解决的问题

| 类别 | 问题 | 建议 |
| --- | --- | --- |
| 资质 | 用户的钱付给各家门店，可能被认定为多商户平台，类目、许可和平台责任都更重 | 开发前请律师和微信支付服务商定性 |
| 支付 | 每家加盟店单独进件，按摩类可能需要额外审核，个体户材料不全 | 先拿 1–2 家试点店真实走一遍进件 |
| 第三方服务 | 短信、虚拟号码、外呼、实名核验供应商对按摩行业可能有审核 | 提前确认，文案统一用"上门服务"这类中性说法 |
| 培训和证书 | 办学许可、证书性质决定"持证技师"能不能这么宣传 | 资质不足时改口径为"天俪培训认证" |
| 技师用工 | 集团签约再派到加盟店，可能构成劳务派遣 | 技师直接和门店签约，集团负责培训和推荐；或集团办理许可 |
| 加盟合同 | 原合同没有平台抽成、集团裁决权、数据归属、退出清算等条款 | 起草补充协议，先和试点门店谈下来 |
| 门店人手 | 小门店店长盯不过来派单、售后和求助 | 集团调度和客服兜底，人力成本算进预算 |
| 上门条件 | 按摩床怎么带、交通方式、雨天和深夜 | 实地调研；一期可以先做不需要床的项目 |
| 服务伤害 | 按摩导致受伤的纠纷 | 职业或公众责任险、理赔流程、危机预案 |
| 个人信息 | 身份证号、行踪轨迹、人脸属于敏感个人信息 | 做个人信息保护影响评估，按等保二级准备 |
| 组织 | 培训、加盟、运营、财务、法务是否参与评审 | 明确牵头人，关键决定由业务部门拍板 |

**建议开发前先花 2–4 周做落地预审**：定性和资质、用工结构、加盟补充协议、试点门店实地调研、成本预算。都定了再确定开发范围和报价。
