
## 新增经营管理

本批新增入口：门店/集团侧栏“经营待办 / 预约待办”和“店内忙碌 / 忙碌核实”；技师、店长从工作台待办或排班页进入。历史预约详情可“再次预约”，仍沿原分步预约确认。

- 技师本人或本店负责人登记实际忙碌，支持延长和结束；超时保持占用，已有预约冲突交门店协调。
- 待办数字可进入记录并处理；“无登记占用”仅供核实。历史实收实退单独统计，服务分账、提成与发放从“服务财务”查看。
- 门店改约候选须在原最早提前量外预留完整 15 分钟确认窗口；自主预约/改约的原提前量不变。
- 商品售后按商品行计算可申请额度，案件展示历史规格、SKU 和数量；普通联系门店保留到预约完成、取消之后。

从[集团商品管理](http://127.0.0.1:4188/integrated-v5/#/group/catalog)进入：新建商品草稿 → 维护规格/售价/佣金 → 库存入库 → 预览并发布 → 用户选购 → 集团出库 → 用户收货。商品资料和库存各有入口，记录按同一商品/规格编号关联。新建资料无需修改代码。

- 分类、图片详情、多规格、草稿/上下架、改价、版本和影响确认；历史单保留原名称、价格与佣金。
- 入库、盘点、报损、低库存、占用订单和库存流水；盘亏不能扣掉有效订单占用。
- 项目日夜价/时长/加时、预约范围规则；门店资料/经营项目、技师档案/导入/资质审核接入原预约。
- 页面顶部集团岗位可切换管理员、运营、仓储、客服、财务。此为本地岗位演示，正式账号及服务端鉴权仍待接入。
- 草稿保存在当前标签，校验失败不丢失；跨标签版本冲突须核对后重编。门店暂停、技师停接前展示在途预约，完整调店/关店清算仍待第二批。

补齐清单及后续范围见[09](../../docs/整合版-v0.5/09-经营管理完整度与补齐清单.md)。

## 服务资金连续演示

集团财务在“服务财务→财务规则”显式发布Demo规则 → 用户按原流程预约支付 → 技师确认、完成 → 完成满48小时且无阻断 → 集团逐笔分账、查询未知结果、分别完结 → 门店按月登记实际线下发放。分账比例和提成初始为空；旧单缺快照不按现行规则补算。

已结算后退款：集团客服在完成超过48小时、未超过30天时登记特批受理 → 原集团裁决 → 财务主款/加时逐笔退款 → 内部回退或线下追偿 → 已发提成生成差额并由门店登记实际追回/补发。原发放流水始终保留，不自动扣下期。用户退款独立于内部回退。

本轮带完整验收数据的[4198服务账本](http://127.0.0.1:4198/integrated-v5/#/group/service-finance/ledger)与旧端口隔离。该端口手工发布的15%/5%和40%只用于验算，不是正式经营参数。

## 原预约操作

首页 → 片区/门店 → 项目 → 就近或指定技师 → 日期与可约时段 → 联系人 → 首次身份授权与核验演示 → 成年及健康告知 → 确认预约 → 付款结果。首页已选门店与项目时，仍可用原快捷入口直接选技师。

- 时间按半小时选择并显示总价，休息、请假、占用及时间范围限制直接显示。付款前再次核对具体技师和金额。
- 返回、刷新、切角色继续本标签页的本人草稿；用户之间隔离。切门店/项目/偏好会清理失效技师和时间，保留联系人；另一标签页的业务更新不覆盖本页草稿。
- 技师和本店工作端可编辑常规或指定日期的工作/休息时间，已有有效预约及变更占位会阻止冲突保存；派单前先显示可用候选和禁选原因。
- 新建演示默认午休 12:00–13:00。旧 schema 5 未保存排班时兼容原 09:00–23:00、无固定休息；不必清数据，不追溯改已有预约。保存新排班时才校验并记录。
- 位置允许/拒绝为本地演示，拒绝后仍可手选片区；真实定位未接入。支付结果由页面顶部演示设置控制，用户确认页仍使用“确认并支付”。

## 六步连续演示

1. **门店推荐选购。** 用户首页进入幸福里门店“推荐好物”，把修复液标准瓶 200 元、蛋白粉 100 元各加入一件。确认页应显示幸福里来源，购物车此时未占库存。
2. **预约另一家门店。** 保留购物车，创建银杏门店的预约，核对具体技师和时间后模拟付款。切该技师确认，或切银杏店长派单；推进到预约时间开始，满预约时长后完成。用户、该店和集团看到同一预约，幸福里商品来源不变。
3. **提交商品并付款。** 回用户购物车，核对本人地址、幸福里来源、商品 300 元及运费 10 元，提交 310 元商品订单。可以先演示支付失败，再进入处理中并查询成功；处理中不能重复付款。
4. **集团发货、本人收货。** 集团打开刚创建的商品订单登记运单，用户在本人订单确认收货。演示设置推进 7 天，满足本版等待条件后出现可结商品佣金。
5. **门店核对、集团付款。** 集团为幸福里生成 40 元账单，切幸福里门店核对，集团提交付款，再查询模拟渠道结果。也可演示差异复核和原交易失败重试。
6. **售后与追回。** 用户对修复液提出一件退货、协商退 100 元，集团受理、用户寄回、集团验收并退款：净额 210 元、商品佣金 30 元，已付部分产生 10 元追回；集团登记回款后结清。用户另申请只退运费 10 元并由集团处理后，净额为 200 元，商品佣金仍为 30 元，不新增追回。不同退货金额会产生相应结果，这些数值仅用于演示验算。

异常分支从当前订单继续：预约拒绝/派单到期、指定改派确认、紧急请假、求助后完成、加时与分笔退款；商品未发货取消、退货验收分歧、申诉复核、拒退原货返还。演示设置可重置**本版**本地数据。

## 商品异常连续演示（第九批）

用户商品订单：发货前更换本人同省同市地址／按商品取消 → 集团客服批准取消 → 仓储发剩余商品 → 财务原笔退款。物流异常由客服或仓储登记事实和人工跟进时间，客服提出方案，用户在原单确认；订单实际收货或原退款成功后才会办结对应异常。

退货只实收部分时，仓储登记数量/证据，客服逐案填写方案，用户可拒绝并继续核查，也可确认实收数量的处置及未寄回商品由本人保留。随后走原验收入库／原货返还及退款。未寄回可主动撤回；原货返还未收取继续跟进，到期不会自动销毁或扣款。

带完整本地验收数据的[4204异常已办列表](http://127.0.0.1:4204/integrated-v5/#/group/tasks?category=goods-exception&status=done&q=G1001)可追溯G1001三条异常；独立4205保留商品图片与发票验收数据。[第18节](../../docs/经营闭环补充-2026-10-03.md#18-第九批商品订单异常闭环与遗留运行验收)为唯一执行清单，正式政策与未验收附件项继续保留。
