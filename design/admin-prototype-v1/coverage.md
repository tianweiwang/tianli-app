| 售后处理 | 诉求和逐笔申请、同意/协商/驳回、用户决定、集团介入、比例到分拆分、部分失败及重试 |
| 技师与排班 | 周视图及单日编辑、历史只读、占用阻止排班缩短、普通请假冲突提示、紧急请假影响筛选 |
| 投诉与评价 | 评价列表、技师申诉、门店初审、提交集团终审 |
| 对账与提成 | 支付/成功退款/处理中分列、快照抽成预估、提成和补贴、发放凭证编号、退款后差额提示、CSV |
| 发票管理 | 待开、开票及驳回、凭证文件名、退款触发待红冲、红冲后按净额重开 |
| 门店推广 | 推广员列表、邀请为待签约、有效状态管理、绑定数及佣金 |
| 门店规则 | 提成/补偿/半径/缓冲配置、发布版本、比例校验；旧预约价格和比例保留 |
| 门店设置 | 基础资料、营业时段、提前24小时设置暂停、未开始预约清单、暂停时段阻止候选 |
| 安全值班 | 值班人员、接报、3/6分钟无人响应投影、记录结果、结案时保留未解争议与履约事实 |

## 已核验的关键规则

- 门店派单直接进入已确认，首次派单不重计截止；已确认变更开新轮，期限取新轮30分钟与新开始前60分钟较早值。
- 指定改派保持原安排至用户决定；拒绝全退。门店改约拒绝或超时保持原约。
- 排班、请假、资格、保单、营业时段、暂停、预约及拟约占用共同影响候选。
- 普通请假先协调；紧急请假只重派本人、重叠、已确认且未开始履约的预约。已开始和已完成事实保持。
- 协商100元按98:49申请额分成66.67与33.33元。重试仅执行失败笔，已退与处理中分别记账。
- 安全结案按未解争议继续阻断；核实无争议后恢复事实投影，保留开始和完成时间。
- 价格、集团抽成保持原快照；技师提成在首次分配或更换技师时固定当时版本。
- 已登记提成保留原金额和凭证；后续退款显示待调整差额。样例补贴沿用需求的每主预约10元。
- 发票随退款转待红冲，退款未定或待红冲时不能重开；重开金额使用净收款。
- 门店只见本店样例、导出仅当前筛选；集团路由对门店汇总身份不可见。真实认证和细分账号权限仍由服务端实现。

## 继续细化的规划项

这些属于后端规划范围，本版尚未做成完整交互链，不计为本次已覆盖：

- V3/V4完整事实证据、爽约双向确认、服务中止核实、较重处罚及申诉、正式联系通道。
- 日账单导入与差异核对、退款待垫付、逐笔回退、强制分账日、月度服务费开票、追偿核销、分销税务汇总。
- 多支付来源/跨店/首单归属的完整分成样例，提成调整流水与后续月度补扣。当前交易样例固定为集团自然客户，无推广佣金。
- 门店新建与进件补件、关店清算、技师调店及离职清算、导入错误文件下载、真实资料预览。
- 项目新建/定时发布、规则历史对比、门店推广码、协议版本、客户归属历史、用户注销留存。
- 日期区间和高级组合查询、分页与批量任务、图表钻取、导出异步进度和过期；本版样例列表一次展示并直接导出CSV。
- 七类细分后台权限、字段与附件授权、敏感访问理由、会话撤销、真实通知失败重试及值班覆盖校验。

上线前仍需落实后端规划中真实地点、取消费用事实来源、首单规则等决策。原型中的本地状态校验不能代替服务端鉴权、并发控制和资金幂等。
