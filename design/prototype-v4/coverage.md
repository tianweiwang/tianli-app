# 预约版 v4 覆盖与验证

## 要求与实现映射

| 用户要求 / 已确认规则 | 本版位置 |
| --- | --- |
| 另建一版，保留原 v3 | 独立 `prototype-v4`；独立演示存储与 4184 服务 |
| 选择门店、项目、技师和时间 | U01–U12，用户预约组 |
| 定位、就近派技师 | 片区授权/拒绝、手选片区；同店项目资格、偏好、排班/请假/占时/距离筛选 |
| 页面只呈现预约，不写到店 | 三类端页面及画廊使用统一预约词，移除原行程环节 |
| 三类端共用预约 | demo 外层切换用户/技师/店长，原预约信息与结果共享 |
| 首轮固定截止；确认变更后开新轮 | 支付、门店安排、改约/指定改派、请假重派分别校验状态与截止 |
| 门店安排直接已确认 | `store-assign` 成功直接确认；指定改派先等待用户 |
| 已开始或完成不因请假回退 | 请假按技师与完整起止时间判断，只处理受影响且可重派的已确认预约 |
| 金额与支付归属真实一致 | 项目价格快照、加时独立支付、分笔申请和比例退款、剩余额度、幂等结果查询 |
| 求助结案保留最新终态 | 完成时间、取消/退款终态保持；未解争议继续阻断结算 |

详细服务地点和真实微信能力未接入，不能把片区坐标当作实际地点。未提供真实后台权限、并发抢占或网络故障证明。完整范围和正式接入事项见 [v0.4需求说明](../../docs/预约版-v0.4/需求说明.md)。
